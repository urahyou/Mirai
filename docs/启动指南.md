# 小未来启动指南

小未来由 Electron 负责窗口、界面和对话调度，Python Companion Core 负责生活、情绪与本地记忆。长期记忆保存在 Electron 用户目录下的 `memory.db`，不使用 Docker、embedding 模型或网络记忆服务。

## 启动

```bash
cd /Users/urahyou/Desktop/Mirai
npm start
```

开发模式会打开 DevTools 并打印渲染进程日志：

```bash
npm run dev
```

需要语音时，先安装本机语音依赖，再使用带语音的启动命令：

```bash
npm run setup:voice
npm run start:voice
```

## 本地记忆

应用启动时会受管启动 `companion-core/server.py`。它通过 stdin/stdout JSON Lines 与 Electron 通信，不监听网络端口。数据库位置为 Electron `userData/memory.db`，包含：

- 聊天情景记忆
- 已确认事实与人物画像
- 关系图边与来源关联
- 互动事件、虚拟生活活动
- 每日和每周日记的事实素材

聊天检索默认在本地合并关键词命中的情景、当前有效事实和最多一跳的关系图，再按固定容量注入模型上下文。可在 `.env` 中显式设置 `MIRAI_EMBEDDING_ENABLED=true`、OpenAI 兼容的 `MIRAI_EMBEDDING_BASE_URL` 与 `MIRAI_EMBEDDING_MODEL`，让后台为已归档 Episode 建立向量索引，并把语义候选与关键词/图候选统一去重排序。默认关闭时不会探测或请求 embedding 服务，也不依赖外部数据库；服务异常时自动退回原有检索。

Python Core 未就绪时，普通聊天仍可运行，但不会读取或写入长期记忆；它不会回退到旧服务。

## Agent 提案

Agent 默认关闭。启用前需在 `.env` 显式设置 `MIRAI_AGENT_ENABLED=true`、`MIRAI_AGENT_PI_PROVIDER` 和 `MIRAI_AGENT_PI_MODEL`，并在 Pi 自己的凭据存储中完成登录。设置中心的「Agent 提案」只支持本地草稿：Pi 先返回标题与正文提案，用户批准后写入 `userData/agent-drafts/`；不会执行终端命令、任意路径写入、真实消费或发送消息。

## 感知与隐私

「与小未来相处」面板会列出系统状态、天气和屏幕观察来源。每项拥有独立开关、TTL、权限/可用状态和清除动作。系统状态来源默认启用；天气需要先填写本地经纬度，再手动开启，使用 Open-Meteo 获取当前天气；屏幕来源默认关闭；macOS 开启后只读取前台应用并映射为“专注工作/浏览网页/阅读或编辑”等类别，不保存应用名、窗口标题、截图、OCR 或剪贴板内容。辅助功能权限不足时显示为拒绝并停止重试。关闭来源或清除位置后采集器立即停止并清空短时快照，TTL 到期的数据不再注入对话；高敏感原始内容不写入长期记忆。

## 检查

```bash
npm run check
```

该命令会执行 Node 语法检查、Node 测试和 Python Core 测试。

## 停止

关闭 Electron 窗口即可结束桌宠与受管的 Python Core。若语音侧车因异常残留，可单独结束：

```bash
pkill -f 'voice-sidecar/sidecar_server.py'
```
