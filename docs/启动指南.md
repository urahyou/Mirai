# 小未来启动指南

小未来由 Electron 负责窗口、界面和对话调度，Python Companion Core 负责生活、情绪与本地记忆。长期记忆保存在 Electron 用户目录下的 `memory.db`，不使用 Docker、embedding 模型或网络记忆服务。

## 启动

```bash
cd /Users/urahyou/Desktop/Mirai
npm start
```

开发模式会打开 DevTools 并打印渲染进程日志：

```bash
npm run dev
```

需要语音时，先安装本机语音依赖，再使用带语音的启动命令：

```bash
npm run setup:voice
npm run start:voice
```

## 本地记忆

应用启动时会受管启动 `companion-core/server.py`。它通过 stdin/stdout JSON Lines 与 Electron 通信，不监听网络端口。数据库位置为 Electron `userData/memory.db`，包含：

- 聊天情景记忆
- 已确认事实与人物画像
- 关系图边与来源关联
- 互动事件、虚拟生活活动
- 每日和每周日记的事实素材

聊天检索默认在本地合并关键词命中的情景、当前有效事实和最多一跳的关系图，再按固定容量注入模型上下文。可在 `.env` 中显式设置 `MIRAI_EMBEDDING_ENABLED=true`、OpenAI 兼容的 `MIRAI_EMBEDDING_BASE_URL` 与 `MIRAI_EMBEDDING_MODEL`，让后台为已归档 Episode 建立向量索引。默认关闭时不会探测或请求 embedding 服务，也不依赖外部数据库；语义候选融合将在后续里程碑启用。

Python Core 未就绪时，普通聊天仍可运行，但不会读取或写入长期记忆；它不会回退到旧服务。

## 检查

```bash
npm run check
```

该命令会执行 Node 语法检查、Node 测试和 Python Core 测试。

## 停止

关闭 Electron 窗口即可结束桌宠与受管的 Python Core。若语音侧车因异常残留，可单独结束：

```bash
pkill -f 'voice-sidecar/sidecar_server.py'
```
